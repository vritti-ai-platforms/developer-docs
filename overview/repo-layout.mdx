Everything that provisions Vritti lives in a single repo, `infrastructure/`. Each top-level folder owns
one concern, and the `justfile` at the root ties them together. Nothing sensitive is committed — every
command runs under `infisical run` (see [Secrets flow](/infisical/secrets-flow)).

## The `infrastructure/` folder

```
infrastructure/
├── tofu/          OpenTofu roots + reusable VM module (Excloud + Cloudflare)
├── ansible/       Host provisioning: the cloud stack + the core agent
├── infisical/     The self-hosted Infisical compose stack
├── images/        Shared container images (postgres-pgbackrest)
├── justfile       Task runner fronting every tofu + ansible command
└── .github/       CI workflows
```

| Folder | Purpose |
|---|---|
| `tofu/` | OpenTofu roots (`network`, `cloud`, `apw1`) — each with its own R2 remote state — plus `modules/excloud-core-vm`. Provisions Excloud VMs, reserved IPs, Cloudflare DNS, and the Zero-Trust tunnel. |
| `ansible/` | Two self-contained sub-projects: `cloud/` (the fixed control-plane VM + compose stack) and `core/` (any agent-hosted core VM), plus shared `roles/`. |
| `infisical/` | The `docker-compose.yml` for the self-hosted Infisical instance (app, proxy, redis, postgres, pgBackRest backups). |
| `images/` | `postgres-pgbackrest` — the shared Postgres 18.4 + pgBackRest image used by the cloud, core, and Infisical stacks. |
| `justfile` | Every recipe wraps `infisical run` so tofu + ansible get their secrets. Bare `just` lists them all. |
| `.github/` | CI workflows for the repo. |
